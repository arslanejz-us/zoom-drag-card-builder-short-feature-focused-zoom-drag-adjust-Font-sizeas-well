# Interactive Card Designer with Fabric.js & Interact.js

This project is a **custom member card designer** built with **Fabric.js** and **Interact.js**, allowing users to dynamically edit, position, and style content in real time. It’s designed for use within a web interface (e.g., WordPress or standalone JS app).

---

## 🚀 Features

- 🖼 **Image Manipulation**
  - Zoom in / zoom out functionality.
  - Drag the image within a fixed circular or rectangular boundary.
  - Maintain aspect ratio and constraints.

- ✏️ **Text Controls**
  - Add and edit text dynamically.
  - Change font size, color, and position in real time.
  - Drag text elements anywhere on the canvas.

- 🧭 **Canvas Interaction**
  - Smooth and responsive drag behavior using Interact.js.
  - Real-time resizing and positioning.
  - Layered element management (image behind, text above).

- 🎨 **Design Output**
  - Canvas exports as a **high-quality image or PDF**.
  - Designed for **300 DPI** print resolution.
  - Supports background customization and bleed-safe layout.

---

## 🛠 **Tech Stack**

- **JavaScript**
- **Fabric.js** – for canvas and image manipulation
- **Interact.js** – for drag, drop, and resize interactions
- **HTML5 Canvas**
- **CSS3** for layout and styling
